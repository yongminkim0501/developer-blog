# DEV.LOG design direction

## 기준

2026-09-05 합의: 프론트엔드를 먼저 구현한다. 토스 클론 프로젝트는 시각적 레퍼런스로만 참고한다. 토스의 페이지·컴포넌트를 1:1로 재현하거나 로고·이미지·문구·일러스트·제품 전용 UI를 복제하지 않는다.

추출하는 원칙은 타이포그래피 위계, 충분한 여백, 그리드, 간격, 이미지 처리, 모서리 반경, 반응형 동작이다. 결과물은 개발 기록을 위한 독자적인 에디토리얼 디자인이어야 한다.

## 적용

- 브랜드: DEV.LOG / Yongmin. 독자적인 워드마크와 별표 모티프.
- 본문 중심: 흰색·짙은 회색, metadata의 절제된 톤, 필요한 곳의 인디고 강조.
- 콘텐츠 영역 1240px, 본문 760px. 모바일에서는 20px 좌우 여백.
- 홈 순서: 소개 → 정글 배너 → 최신 글 3개 → 지나온 시간·수상 → 프로젝트 4개. 최신 글은 3열, 모바일은 한 열.
- 지나온 시간·수상은 한 섹션에 두 열로 배치하고 모바일에서는 세로로 이어진다.
- 다크모드 배경은 `#27272a`(zinc-800), 보조 배경은 `#303033`, 경계선은 `#3f3f46`. 다크모드의 섹션 제목과 보조 링크는 `#fff`.
- H1의 ‘개발자 김용민입니다.’는 `var(--accent)`를 사용한다. 라이트 `#4565e8`, 다크 `#97a8ff`이며 이름에 마우스를 올려도 유지한다.
- 썸네일은 개발 개념을 표현하는 신규 SVG. 카드 전체를 테두리나 그림자로 감싸지 않는다.
- 한글 글꼴은 범용 오픈소스 Pretendard 공식 배포본. OFL 라이선스 포함.

## 스크롤 인터랙션

홈의 블로그 설계 스크롤 섹션은 2026-09-07 제거했다. 프로젝트 상세(`/projects/dev-log`)에는 설명 목적의 스크롤 연동을 유지한다. DEV.LOG에서는 작성 → Git 기록 → 탐색으로 화면을 전환한다. 고정된 화면과 흐름을 설명하는 문장을 결합하되 스크롤을 강제 이동시키지 않는다.

모바일은 정적인 대표 화면과 순차적 설명으로 읽는다. `prefers-reduced-motion` 설정 시 고정 연출과 전환 효과를 줄인다. 일반 글 본문에는 불필요한 등장 지연을 적용하지 않는다.

## 데이터와 향후 기능

초기 샘플 글은 제거하고 실제 학습 글을 게시했다. 검색·조회수는 서비스 인터페이스 뒤의 HTTP 어댑터로 Spring에 연결한다. 2026-09-07 독립 Brain 페이지와 데모 구현을 제거했다. 챗봇은 추후 검색 기능과 통합할 계획이며, CMS·실제 LLM 호출·RAG는 현재 구현에 포함하지 않는다.
