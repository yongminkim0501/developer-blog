## 브라우저 바깥을 생각하기

화면에 표시되는 결과 뒤에는 요청을 만들고, 전송하고, 처리하는 과정이 있습니다. 각 단계를 분리해서 보면 오류가 어디에서 발생했는지 살펴보기 쉬워집니다.

## 요청과 응답의 형태

```http title="request.http"
GET /blog HTTP/1.1
Host: example.com
Accept: text/html
```

서버는 상태 코드와 헤더, 필요한 본문을 응답합니다. 상태 코드만 확인하기보다 실제로 어떤 헤더와 본문이 왔는지 함께 관찰합니다.

## 도구로 확인하기

개발자 도구의 네트워크 탭에서 요청의 순서와 소요 시간, 응답 헤더를 확인해봅니다. 이 샘플을 실제 캡처와 관찰 내용으로 확장할 예정입니다.
